# 什么叫“更有信息”？

*为什么知道得更多，不一定让你做得更好*

> 这篇文章沿着一个很小的盒子游戏，追问一个看起来很简单的问题：当几条信息都可以获得时，我们到底该怎么比较它们？

## Prologue｜如果有几条信息可以选，应该选哪一条？

上一篇文章最后留下了一个问题。

当现有证据已经无法继续区分几种仍然可能的情况，继续围着同一份信息想，并不会凭空产生新的证据。

这时，一个更主动的智能体就要决定：下一步看什么、问什么，或者做什么。

可现实里，下一步往往不只有一个选择。

如果同时有几条信息可以拿，我们应该选哪一条？

直觉上，这似乎不难。

更准确的，应该更好。

知道更多细节的，应该更好。

能排除更多可能情况的，似乎也应该更好。

但这些标准真的会给出同一个答案吗？

先看一个只有四种可能的盒子游戏。

## Chapter 1｜目标固定时，答案其实很简单

桌上有左、右两个盒子。

奖品随机放在其中一个盒子里，同时奖品本身随机是红色或蓝色。

于是隐藏的真实情况一共有四种，而且一开始都同样可能：

| 可能情况 | 奖品位置 | 奖品颜色 |
|---|---|---|
| H₁ | 左 | 红 |
| H₂ | 左 | 蓝 |
| H₃ | 右 | 红 |
| H₄ | 右 | 蓝 |

你最后只能做一个动作：打开左边或者右边的盒子。

现在有两个信息提供者。

A 能够 **100% 准确**地告诉你奖品是什么颜色。

B 不知道颜色，但能以 **75% 的准确率**告诉你奖品在哪一边。为了让例子保持简单，我们假设它的错误是对称的：奖品在左边时，它有 75% 概率说“左”；奖品在右边时，它也有 75% 概率说“右”。

谁提供了更好的信息？

如果先看准确率，A 好像没有悬念。

它说红色，奖品就一定是红色。

B 说左边，却有四分之一的概率说错。

可一旦真正要打开盒子，结果反过来了。

没有任何信息时，左右各有一半概率，随便选一边，成功率是 50%。

听完 A，虽然颜色确定了，奖品仍然有一半概率在左边、一半概率在右边。

成功率还是 50%。

听完 B，如果直接按照它提示的位置行动，成功率却变成了 75%。

所以如果目标已经固定成：

> **尽可能找到奖品。**

答案其实很简单：选 B。

到这里甚至可以反问：既然目标已经告诉我们什么才有用，这篇文章是不是可以结束了？

如果我们只关心这一局游戏，确实可以。

但 A 又明显不是“没有信息”。

它一旦告诉我们“红色”，四种可能就只剩两种：左 + 红，或者右 + 红。

A 排除了一半的可能；B 却更能帮助我们行动。

而且只要把任务改成“判断奖品颜色”，排序马上又会反过来：A 直接把正确率提高到 100%，B 几乎没有帮助。

所以这里其实混着两个不同的问题：

> **我到底知道得更多了吗？**

和：

> **我多知道的这些东西，对现在要做的事有用吗？**

上一篇文章把“区分力”“决策价值”和“获取成本”放在一起。到了这里可以看见，它们并不是同一件事。

## Chapter 2｜A 明明让我知道得更多，为什么却没用？

先暂时忘掉开哪个盒子，只问一个更简单的问题：看完一条信息以后，我们少了多少不确定性？

四种情况一开始完全等概率。

这里其实有两个彼此独立的二选一：位置是左 / 右，颜色是红 / 蓝。

一个完全拿不准的二选一，可以看作 1 bit 的不确定性。因此这个游戏一开始一共有 2 bits：1 bit 来自位置，1 bit 来自颜色。

A 精确告诉颜色，相当于把“红 / 蓝”这个二选一彻底解决。

所以在这个例子里，A 消除了：

```text
1 bit
```

B 不一样。

假设 B 说“左边”，我们对位置的判断会从：

```text
50% / 50%
```

变成：

```text
75% / 25%
```

我们显然比原来更确定了一点，但又没有完全确定。

信息论用 **熵（entropy）** 来给这种“不确定程度”一个数字。`50% / 50%` 的熵是 1 bit，`75% / 25%` 约是 0.81 bits。

所以 B 让位置的不确定性减少了约：

```text
1 - 0.81 = 0.19 bits
```

而 B 并没有告诉我们任何颜色信息，所以对于整个四种可能的世界来说，它平均减少的不确定性仍然约是 0.19 bits。

于是出现了这篇文章最重要的反差：

```text
A：约 1 bit
B：约 0.19 bits
```

如果问题是“谁让我少了更多不确定性”，A 更高。

如果问题是“谁更能帮我找到奖品”，B 更有价值。

两边都没有错。它们只是在回答不同的问题。

这里还有一个很容易忽略的地方：**这 1 bit 和 0.19 bits 都不是信息本身自带的固定标签。**

它们取决于我们原来有多不确定。

比如，如果奖品事前就有 99% 概率是红色，只有 1% 概率是蓝色，那么 A 即使仍然 100% 准确地告诉颜色，也不会再带来 1 bit 的新信息——因为颜色这件事，我们本来就已经几乎知道了。

所以 **information gain** 更像是在问：

> **相对于我原来不知道的东西，这次信息让我少不知道了多少？**

这也解释了为什么同一个信息源，对两个起点不同的人，能带来的新信息可能完全不同。

还有最后一步。

刚才我们是在 B 已经说出“左边”以后算这次信息带来了多少变化。但真正去问 B **之前**，我们还不知道它会说左还是右。

在这个对称的例子里，两种回答各有一半概率，而且无论得到哪一种，不确定性都会减少约 0.19 bits。

所以在询问之前，我们就可以说：问一次 B，**平均预计**会带来约 0.19 bits 的新信息。这就是 **expected information gain** 的基本意思。

如果你想知道熵的公式为什么会出现 `log`，以及 `0.81` 是怎么算出来的，文末附注 1 单独展开；主线先继续往下走。

到这里，我们得到了一种比较信息的方法：

> **看它平均减少了多少不确定性。**

但有些时候，我们想比较的不是“少了多少”，而是两个信息源之间有没有一种更直接的包含关系。

## Chapter 3｜不看当前任务，还能怎么比较？

继续用盒子。

除了 A 和 B，再加入一个信息源 C：

- B：75% 准确地告诉奖品在哪一边；
- C：100% 准确地告诉奖品在哪一边。

这个例子里，光看准确率就知道 C 更好。

但更值得注意的是另一件事。

如果你拥有 C，想模拟 B 很容易：C 每次都告诉你正确位置，你只要完全随机地挑出 25% 的时候，把“左 / 右”故意说反，就得到一个和 B 一样的信息源。

也就是说：

> **C 可以只靠处理自己的答案来模拟 B；B 却无法反过来恢复 C 原本那个确定的答案。**

这就是 **Blackwell comparison** 最重要的直觉。

它不是在问“这一局谁更有用”，而是在问：

> **一个信息源是不是已经包含了另一个信息源能提供的全部能力？**

这里有一个关键条件：模拟 B 的过程只能加工 C 已经给出的答案，不能再偷偷去看奖品到底在哪。

否则它就不是“把已有信息加工得更粗糙”，而是在加工过程中又拿到了新的信息。

在 B 和 C 这个小例子里，这个标准看起来有点大材小用。

它真正有价值的地方，是当一个信息源已经不能只靠“准确率”概括时，我们仍然可以问：它能不能只通过加工自己的输出，生成另一个信息源的输出？

再回到最开始的 A 和 B，情况就不同了。

A 知道颜色，却不知道位置；B 知道一点位置，却不知道颜色。

A 没办法加工出 B 的位置信息，B 也没办法加工出 A 的颜色信息。

所以它们根本不需要被硬排成“一强一弱”。

有些信息源本来就观察了世界的不同部分，因此没有一个统一的先后顺序。

更严格的 Blackwell 定义放在文末附注 2。正文只需要保留这个直觉：

> **如果一种信息可以被“加工”成另一种，而反过来不行，那么前者保留了后者能提供的能力。**

## Chapter 4｜两条信息放在一起以后呢？

还是盒子。

假设一个视觉来源只能看到奖品的局部特写，因此知道它是红色还是蓝色，却看不到它在哪个盒子里。

另一个声音来源看不到颜色，却可以分别晃动两个盒子，根据声音差异，带着一定误差判断奖品在哪一边。

视觉告诉我们颜色，声音帮助判断位置。

这时第二个来源的价值，不在于系统突然多了一种输入格式，而在于它补上了第一种来源看不到的东西。

但两条信息放在一起，也不能简单把各自的“信息量”相加。

有时它们在重复同一件事。两个位置接近、共享盲区的摄像头，即使都说“左边”，第二个结果也不等于又得到了一份完全独立的新证据。

有时它们各自补充不同的部分。视觉告诉颜色，声音帮助判断位置，两者提供的是不同约束。

还有一种更有意思的情况：单独看都没用，放在一起才有用。

想象左右两个盒子上各有一盏灯。规则是：奖品在左边时两盏灯同色，奖品在右边时两盏灯异色。

单独看任何一盏灯，都不知道奖品在哪；同时看到两盏，却能立刻判断位置。

这就是 **synergy** 最简单的直觉：有些信息只有组合以后才出现。

Partial Information Decomposition（PID）试图把“重复、各自独有、组合后才出现”这些关系进一步形式化。这里不展开，因为对这篇文章来说，先记住一个更简单的结论就够了：

> **多一个信息源，不等于简单多一份信息；关键在于它到底补上了什么。**

甚至“看到十次相同结论”也不自动等于十份独立证据，因为它们可能来自同一个错误来源。

## Chapter 5｜最后到底该拿哪一条？

现在回到最开始那个最实际的问题。

如果目标已经固定，真正决定“该不该拿”一条信息的，还是它会不会改善行动。

这就是 **value of information（VoI）** 要回答的问题。

在找盒子的任务里，没有任何信息时，最优成功率是 0.50；获得 B 以后，按它提示的位置行动，成功率是 0.75。

如果我们把“找对盒子”记作 1，“找错”记作 0，那么 B 带来的决策价值就是：

```text
VoI(B) = 0.75 - 0.50 = 0.25
```

但有价值，还不等于值得获取。

如果询问 B 的成本是 0.10：

```text
Net Value(B) = 0.25 - 0.10 = 0.15
```

值得问。

如果成本是 0.30：

```text
Net Value(B) = 0.25 - 0.30 = -0.05
```

它仍然能改善判断，却已经不值得买。

所以，在本文这种“先拿一次信息，再马上做决定”的设定里，只要任务和成本都已经给定，最开始那个简单答案其实一直是对的：

> **选那条最能改善当前决定，而且扣掉成本以后仍然最值得的信息。**

第四篇之所以没有在 Chapter 1 就结束，是因为“更有信息”这句话，本身就可能在问不同的东西。

现在可以把它们放在一张表里：

| 你真正想问什么？ | 可以怎么比较？ |
|---|---|
| 它让我少了多少不确定性？ | information gain |
| 一个信息源是否包含另一个的能力？ | Blackwell comparison |
| 几个信息源放在一起到底新增了什么？ | redundancy / unique / synergy |
| 它会不会让我做出更好的决定？ | value of information |
| 改善值不值得它的成本？ | net value after cost |

这些不是五个互相竞争的“信息定义”。

它们只是五个不同的问题。

所以，上一篇留下的三个词也可以重新理解：

**区分力**不是一个单一分数，而要继续问：少了多少不确定性？一种信息能不能包含另一种？多种来源之间是不是重复或互补？

**决策价值**则一定要看当前到底想做什么。

**获取成本**最后决定，一条有用的信息是不是值得现在去拿。

> **知道得更多，和做得更好，是两件相关但不同的事。**

## 附注｜不影响主线，可以跳过

### 附注 1｜为什么 entropy 里会出现 log？

这不是完整的公理化推导，只是解释公式为什么有这样的形状。

假设一次公平抛硬币出现正面，事前概率是 `1/2`。我们把它带来的 information 定成 1 bit。

如果两次独立抛硬币都出现正面，联合概率是：

```text
1/2 × 1/2 = 1/4
```

而两次独立结果带来的 information 应该可以相加：

```text
1 bit + 1 bit = 2 bits
```

所以我们希望找到一个函数，能把“概率相乘”变成“information 相加”。`log` 正好满足：

```text
log(p₁p₂) = log(p₁) + log(p₂)
```

又因为概率越小，information 应该越大，所以加上负号，并以 2 为底：

```text
I(p) = -log₂p
```

今天通常把这样的 `I(p)` 叫作 **surprisal**。

在结果发生以前，我们不知道最后会看到哪一种结果，于是把每种结果的 surprisal 按它自己的概率取平均：

```text
H(X) = Σ pᵢ I(pᵢ)
     = -Σ pᵢ log₂pᵢ
```

对于概率分别是 `p` 和 `1-p` 的二选一问题：

```text
H(p) = -p log₂p - (1-p) log₂(1-p)
```

因此：

```text
H(0.5) = 1 bit
H(0.75) ≈ 0.81 bits
H(1) = 0 bit
```

某个具体结果发生后的 `-log p` 是 surprisal；结果发生前的平均 surprisal 是 entropy；一条信息让前后的 uncertainty 减少多少，才是正文真正关心的 information gain。

### 附注 2｜Blackwell comparison 更严格地在说什么？

假设两个 experiments 都在观察同一个 payoff-relevant state。

如果 experiment C 的 observation 可以经过一个**不依赖真实 state**的随机后处理，变成 experiment B 的 observation，那么 B 可以看作 C 的 garbling。

这时，拥有 C 的决策者如果真的想按 B 的方式行动，可以先把 C 经过随机后处理变成 B，再使用任何只依赖 B 的策略。

因此，在相应的 Bayesian decision problems 中，拥有 C 所能达到的最优期望收益不会低于只拥有 B。

Blackwell comparison 比“某一个任务里 accuracy 更高”更一般：它比较的是 observation structure，而不是某一个特定 payoff 下的一次胜负。
