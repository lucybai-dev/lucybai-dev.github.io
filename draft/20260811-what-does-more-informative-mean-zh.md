# 什么叫“更有信息”？

*为什么知道得更多，不一定让你做得更好*

> 你不需要预先了解信息论、Blackwell ordering 或 value of information。本文只用一个四种可能世界的盒子游戏，试着回答一个看起来很简单的问题：当两条信息都可以获得时，哪一条才算“更有信息”？

## Prologue｜哪一条信息更值得知道？

上一篇文章最后留下了一个问题。

当现有 evidence 已经无法继续区分仍然可能的世界，继续围绕同一份信息思考，并不会凭空产生新的 observation。

这时，一个更主动的智能体需要决定下一步去看什么、问什么，或者做什么。

但当时我其实跳过了一步。

如果下一步不只有一种 observation 可以获得呢？

如果面前同时有两条信息，我们应该选哪一条？

直觉上，这似乎不难。

更准确的，应该更好。

知道更多细节的，应该更好。

能排除更多可能世界的，似乎也应该更好。

上一篇文章里，我把“区分力”“决策价值”和“获取成本”并排放在一起。那时它们看起来像是在描述同一件事的不同方面。

后来我发现，它们其实可能给出完全相反的答案。

为了把问题缩到足够小，我们先回到一个只有四种可能世界的盒子游戏。

## Chapter 1｜一条完全准确的信息，为什么可能没有用？

桌上有左、右两个盒子。

奖品随机放在其中一个盒子里，同时奖品本身随机是红色或蓝色。

于是隐藏的真实状态一共有四种等概率可能：

| 可能世界 | 奖品位置 | 奖品颜色 |
|---|---|---|
| H₁ | 左 | 红 |
| H₂ | 左 | 蓝 |
| H₃ | 右 | 红 |
| H₄ | 右 | 蓝 |

你最后只能做一个动作：打开左边或者右边的盒子。

现在有两个信息提供者。

A 能够 **100% 准确**地告诉你奖品是什么颜色。

B 不知道颜色，但能以 **75% 的准确率**告诉你奖品在哪一边。

谁提供了更多信息？

如果先看准确率，A 好像没有悬念。

它说红色，奖品就一定是红色。

B 说左边，却有四分之一的概率说错。

可一旦真正要打开盒子，结果反过来了。

没有任何信息时，左右各有一半概率，随便选一边，成功率是 50%。

听完 A，虽然颜色确定了，奖品仍然有一半概率在左边、一半概率在右边。

你的成功率还是 50%。

听完 B，如果直接按照它提示的位置行动，成功率却变成了 75%。

于是第一个问题出现了。

> 一条信息可以完全准确，也确实告诉了我们一个真实事实，却对当前行动没有任何帮助。

但说 A “没有信息”显然也不对。

它说“红色”以后，原来的四个世界只剩两个：

- 左 + 红；
- 右 + 红。

它明明排除了一半可能世界。

所以真正值得追问的不是“A 有没有信息”。

而是：

> **当我们说 A 知道得更多时，这个“更多”到底是什么意思？**

## Chapter 2｜“知道更多”到底是什么意思？

先暂时忘掉开哪个盒子。

只问一个更纯粹的问题：

> 看完一项 observation 之后，我们对真实世界少了多少不确定性？

四个世界一开始完全等概率。

如果要确定真实世界是哪一个，相当于需要解决两个独立的二选一问题：

1. 奖品在左边还是右边？
2. 奖品是红色还是蓝色？

一个完全不确定的二选一问题，可以看作 1 bit 的不确定性。

因此四个等概率世界一开始有：

```
log₂4 = 2 bits
```

的不确定性。

A 精确告诉颜色，相当于把第二个二选一问题彻底解决。

四个世界缩成两个，所以 A 消除了 1 bit 的不确定性。

B 不一样。

为了让例子保持简单，我们假设两件事：奖品的位置和颜色彼此独立；B 的错误是对称的，而且它的输出只依赖位置，不额外透露颜色。

假设 B 说：“左边。”

我们对位置的判断会从：

```
50% / 50%
```

变成：

```
75% / 25%
```

我们显然比原来确定了一些，但又没有完全确定。

信息论用 **entropy** 来衡量这种不确定程度。

对于概率分别为 `p` 和 `1-p` 的二选一问题：

```
H(p) = -p log₂p - (1-p) log₂(1-p)
```

这个公式最值得先记住的不是长相，而是它的两个端点。

当概率是 `50% / 50%` 时，我们最拿不准：

```
H(0.5) = 1 bit
```

当概率是 `100% / 0%` 时，答案已经确定：

```
H(1) = 0 bit
```

`75% / 25%` 位于两者之间：

```
H(0.75) ≈ 0.81 bits
```

所以关于“奖品在哪边”这件事，我们原本有 1 bit 的不确定性，听完 B 以后还剩约 0.81 bits。

B 消除的约是：

```
1 - 0.81 = 0.19 bits
```

由于 B 不提供颜色信息，在前面的独立性假设下，它对完整 hidden state 消除的不确定性也约是 0.19 bits。

于是一个有点反直觉的结果出现了：

```
A：约 1 bit
B：约 0.19 bits
```

按照“平均减少多少不确定性”这个标准，A 的确比 B 更有信息。

这就是 Shannon 信息论提供的一种非常精确的答案。

如果 observation 还没有发生，我们还可以进一步问：把未来各种可能 observation 带来的 entropy 下降按其出现概率取平均，这次观察预计能减少多少不确定性？

这就是 expected information gain 的基本直觉。

可问题没有消失。

A 在这个意义上提供了更多 information。

B 却让我们更容易找到奖品。

两个答案都没有算错。

那它们到底在比较什么不同的东西？

## Chapter 3｜重要的不只是切掉多少世界，而是切掉哪些世界

把 hidden state 写得更明确一点：

```
H = (L, C)
```

其中 `L` 是位置，`C` 是颜色。

A 很有效地约束了 `C`，却完全没有约束 `L`。

B 对完整世界提供的信息少得多，却直接约束了 `L`。

而你最后的行动——开左边还是右边——恰好只取决于位置。

所以这里其实混着两个不同的问题：

> observation 一共减少了多少不确定性？

和：

> observation 减少的是哪一部分不确定性？

把例子再夸张一点就更明显了。

假设另一个信息源能够精确告诉你：

- 奖品是什么颜色；
- 是什么材质；
- 序列号是多少；
- 哪一天生产；
- 包装上印了几个字；
- 重量精确到多少克。

它可能让你知道大量关于奖品的事实。

如果这些变量都被放进 hidden state，它甚至可能获得很高的 information gain。

但只要它始终不告诉你奖品在左边还是右边，你打开盒子的成功率仍然只有 50%。

这让我重新意识到，前三篇一直讨论的其实是同一条线。

第一篇问的是：

> representation 应该保留什么差异？

第二篇问的是：

> 在真实状态不可见时，哪些 possible worlds 仍然能够成立？

第三篇继续问：

> 当现有 observation 无法再区分这些世界时，怎样主动制造新的 evidence？

现在问题又向前走了一步：

> **如果可以选择下一条 evidence，我们最值得去区分哪些世界？**

这时，“知道更多”和“知道对行动重要的东西”终于分开了。

## Chapter 4｜两条 information 放在一起以后发生了什么？

一旦 hidden state 本身包含多个维度，另一个问题也自然出现了。

一种 observation 不一定能从所有方向看见同一个世界。

还是刚才的盒子。

假设一个视觉 channel 只得到奖品的局部特写，因此能够准确判断它是红色还是蓝色，却看不到它位于左边还是右边。

另一个空间音频 channel 看不到颜色，却能根据声音来自哪一侧，带着一定误差判断奖品的位置。

视觉主要约束颜色 `C`。

声音主要约束位置 `L`。

两个 channels 面对的是同一个 hidden state，却在切 hypothesis space 的不同方向。

从这个角度看，多模态可能有价值，并不是因为输入格式从一种变成了两种。

真正可能增加的是：

> **新的 channel 排除了旧 channel 无法排除的那些世界。**

但这里又不能简单地说：两个 channels 放在一起，information 就等于两边相加。

至少有三种完全不同的情况。

### 第一种：重复

两个摄像头都在判断奖品位于左边还是右边，而且位置接近、视角接近、共享同一个盲区。

第一个摄像头已经告诉你“左边”。

第二个摄像头也告诉你“左边”。

第二条 observation 可能有新增价值，但它显然不是又得到了一份完全不同的信息。

### 第二种：各自独有

视觉告诉颜色。

声音帮助判断位置。

一个 channel 排除的是“颜色不对”的世界，另一个排除的是“位置不对”的世界。

它们提供的是彼此没有的约束。

### 第三种：只有组合起来才出现

假设有两个随机开关 `A` 和 `B`，每个都可能是 0 或 1。

我们真正想知道的不是 A 或 B 本身，而是：

> 两个开关是否相同？

如果只告诉你 `A = 0`，你完全不知道它们是否相同，因为 B 可能是 0，也可能是 1。

只告诉你 B 也一样。

但如果同时知道：

```
A = 0
B = 1
```

你马上知道它们不同。

任何一个 observation 单独看都不能回答目标问题，两个放在一起却可以。

这就是 **synergy** 最小的直觉。

Williams 和 Beer 提出的 partial information decomposition，简称 PID，正是试图把这类问题形式化：多个 sources 关于同一个 target 的信息中，哪些是重复的，哪些是各自独有的，哪些只有联合以后才出现。

但这里需要小心。

PID 提供了一个很有用的问题框架，并不意味着 redundancy、unique information 和 synergy 已经有唯一公认的分解定义。后续研究提出了不同方案，这个问题本身仍然是研究对象。

对这篇文章来说，更重要的是它提醒我们：

> **多个 channels 的价值不能只看每一个 channel 单独有多少 information，还要看它们彼此是什么关系。**

不过，“内容重复”还不是最危险的情况。

十篇新闻都报道同一件事，可能只是重复。

如果继续追进去，发现十篇新闻全部引用同一条未经证实的原始消息，那问题就变成了另一件事：它们的错误来源也是相关的。

十篇报道，不等于十个独立 evidence。

三个模型给出相同答案，也不一定等于三个独立判断。

它们可能使用相似训练数据、相似检索源、相似方法，甚至共同依赖同一个上游信息。

如果系统把高度相关的 observations 当作彼此独立的 evidence 反复计算，就会得到一个看起来非常确定、其实只是把同一个来源重复放大的 belief。

所以当多个 channels 放在一起时，我们至少要问两层问题：

> 它们提供的是重复、独有还是协同的约束？

以及：

> 它们的错误到底有多独立？

## Chapter 5｜什么时候我们真的可以说：一个 channel 更强？

讲到这里，好像所有 information sources 都变得无法比较了。

但有一类情况其实很清楚。

两个 channels 观察的是同一件事，而其中一个只是另一个更模糊、更 noisy 的版本。

假设 C 和 D 都只判断奖品位置。

C 的准确率是 90%。

D 的准确率是 70%。

我们当然很想说 C 更强。

但如果只说“因为 90% 大于 70%”，这个理由还只停留在这一个数字上。

换一种方式想。

先让 C 给出答案。

然后再独立地以 25% 的概率，把 C 的“左 / 右”输出随机翻转一次。

最终答案正确的概率会变成：

```
0.9 × 0.75 + 0.1 × 0.25 = 0.70
```

也就是说，我们可以从 C 出发，人为加上一层额外噪声，刚好制造出 D。

关键并不只是 C 更准。

而是：

> **拥有 C 的人，随时可以故意把自己的 information 变差，模拟出 D；只有 D 的人却不能把已经丢掉的信息恢复回来。**

这里还有一个非常重要的条件。

那次随机翻转不能偷偷查看真实状态。

也就是说，“要不要翻转”的规则必须与奖品真实在左还是右无关。

否则它就不再只是给 observation 加噪声，而可能在后处理中偷偷加入新的 state information。

Blackwell 比较 experiments 时抓住的，正是这种关系。

如果一个 experiment 的 observation 可以通过一个与真实 state 无关的随机后处理，变成另一个 experiment 的 observation，那么前者在 Blackwell 意义下至少和后者一样 informative。

更严格地说，在以同一个 payoff-relevant state 为基础、按照期望效用做选择的 Bayesian 决策问题中，拥有前者能够达到的最优期望收益，不会低于只拥有后者。

这个比较比“某一次任务里准确率更高”更强。

因为拥有 C 的人如果哪天真的想按 D 的方式行动，完全可以先把 C 自己降质成 D，再使用 D 的策略。

但只有 D 的人无法反过来恢复 C。

同时，这也解释了为什么很多不同 modalities 之间根本没有一个统一排名。

精确的颜色 channel 和带噪的位置 channel，并不存在这样的退化关系。

它们看的是 hidden state 的不同方向。

此时问“谁普遍更有信息”，可能根本没有答案。

Blackwell ordering 本身就是一种偏序，而不是要求所有 information sources 都排成一条从强到弱的直线。

## Chapter 6｜更有信息，为什么还是可能不值得获得？

现在回到最开始的两个信息提供者。

我们已经知道：

A 在 Shannon 意义下减少了更多关于完整世界的不确定性。

B 却对当前行动更有帮助。

但真实的 agent 还要面对最后一个问题：

> 即使一条 information 有用，我应该为它付出代价吗？

假设选对盒子得到 1 分。

没有信息时，成功率是 50%，当前最优行动的期望收益是：

```
0.5
```

听完 A，左右选择仍然是 50 / 50，所以最优期望收益还是：

```
0.5
```

A 对这个决策的 value of information 是 0。

B 可以把成功率提高到 75%，于是最优期望收益从：

```
0.5 → 0.75
```

增加了：

```
0.25
```

更一般地，一项 query 的 **value of information** 可以理解成：

```
VoI(q)
= 获得 observation 后能够达到的预期最优决策价值
- 没有这项 observation 时的最优决策价值
```

注意这里还没有减查询成本。

如果获取 q 本身需要成本 `c(q)`，更清楚的写法是：

```
Net Value(q) = VoI(q) - c(q)
```

于是是否值得查询，就变成比较：

```
VoI(q) > c(q) ?
```

如果询问 B 只花 0.1 分，它值得。

如果要花 0.3 分，它虽然确实能改善判断，却已经不值得买。

这时，“更值得知道”显然不再只是 observation 自身的属性。

它取决于：

- 你现在相信什么；
- 可以采取哪些行动；
- 不同结果的 utility 是什么；
- 获取 information 要付出什么成本。

于是最开始看起来矛盾的结果终于分开了。

A 改变了更多关于完整世界的 belief。

B 改变了当前任务中更重要的行动边界。

它们没有谁算错。

它们只是在回答不同的问题。

## Chapter 7｜原来“更有信息”根本不是一个问题

回到文章最开始。

A 100% 准确告诉颜色。

B 75% 准确提示位置。

谁更有信息？

现在已经很难只给一个答案了。

如果你问的是：

> 哪条 observation 让我们对完整 hidden state 少了更多不确定性？

A 更高。

这是 information gain 在回答的问题。

如果你问的是：

> 一个 observation mechanism 是否完整保留了另一个 mechanism 能够提供的决策能力？

这更接近 Blackwell comparison。

如果你问的是：

> 在当前任务中，这条 information 能不能让我的行动变得更好？

B 比 A 更有价值。

如果你再问：

> 为了得到它，我应该付多少钱、花多少时间、承担多少风险？

问题又变成了 value of information 和 acquisition cost。

而当多个 channels 同时出现时，我们还要继续问：

> 它们提供的是重复信息、各自独有的约束，还是只有联合以后才出现的信息？

以及：

> 它们真的是独立证据吗？

所以我现在更愿意把“哪条信息更有信息”理解成一个没有完全说清楚的问题。

它至少混合了 information quantity、information ordering、decision value、cost，以及多个 sources 之间的 dependence。

这些概念并不互相竞争。

它们只是从不同角度提醒我们：

> **information 不是事实数量的简单累加。**

一条 observation 的意义，来自它如何改变我们对仍然可能的世界的区分；它与已经拥有的 evidence 是什么关系；以及这些改变最后会不会穿过 belief，真正抵达行动。

这也让我重新理解了多模态。

值得期待的并不是系统单纯拥有了“文本 + 图像 + 音频 + tool”更多输入格式。

更重要的问题是：

> **新的 observation channel，到底让哪些原本无法区分的世界变得可区分了？**

如果它只是在重复已有 evidence，价值可能很小。

如果它与已有 channel 共享同一个错误来源，盲目融合甚至可能制造虚假的确定性。

如果它提供的是新的、互补的，甚至只有联合以后才能出现的约束，它才真正改变了系统能够区分的世界。

## Epilogue｜为什么偏偏让我看见它？

到这里，我们似乎已经把“更有信息”拆得足够细了。

但整篇文章其实一直默认了一件事。

我们默认自己知道 observation 是怎样产生的。

B 为什么有 75% 准确率，我们知道。

C 怎样被加噪声变成 D，我们知道。

不同 channels 是否共享错误来源，至少在理论上也被当作一个可以建模的问题。

现实中，这些东西往往恰恰是未知的。

搜索结果经过排序。

新闻经过选择和转载。

工具接口决定向我们暴露完整状态，还是只返回一个摘要。

传感器有自己的失真机制。

另一个 agent 甚至可能有自己的目标，并主动选择什么告诉我们、什么不告诉我们。

所以 observation 不仅有内容。

它还有自己的生成过程、选择过程和呈现过程。

到了这里，问题就不再只是：

> 哪一条 information 更有信息？

而会继续往下一层走：

> **为什么偏偏让我看见它？**
