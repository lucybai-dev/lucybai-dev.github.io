# 当思考还不够

*当现有证据无法继续区分相互竞争的世界时，行动如何成为推理的一部分？*

> 你不需要预先了解三门问题、贝叶斯推断或因果推断。本文只使用一个规则明确的开门游戏，说明同一项观察为何会因生成机制不同而具有不同意义，以及行动如何成为获取新证据的实验。

## Prologue｜当已有信息说完了它能说的一切

在上一篇文章里，我尝试把推理理解成一件并不神秘的事：

我们看见一些现象，构造出若干仍然可能成立的世界，再用新的事实、规则和行动，一点点排除那些无法继续自洽的世界。

这种方法允许我们暂时保留多个解释，也允许我们承认：在信息不足时，真相未必能够被唯一确定。

但它也留下了一个问题。

如果已经掌握的信息都被充分利用了，而几个世界仍然都能解释眼前的一切，继续思考还有用吗？

有些时候，答案是否定的。

不是因为思考还不够深入，而是因为现有信息已经说完了它能说的一切。

三门问题提供了一个足够小、却包含了几乎全部关键结构的世界。

## Chapter 1｜三扇门和三个世界

你面前有三扇门。只有一扇门后有奖品，另外两扇门后什么也没有。

你先选择了 1 号门。

此时，奖品可能在：

- **世界 1：**1 号门后；
- **世界 2：**2 号门后；
- **世界 3：**3 号门后。

在没有其他信息时，三个世界的概率各是 `1/3`。

你可以继续盯着三扇门思考，也可以分析门的颜色、把手的位置，或者自己为什么选择了 1 号门。

但只要这些细节与奖品位置无关，它们就不会改变三个世界的相对可能性。

思考能够重新组织已经拥有的信息，却不能凭空制造新的证据。

上一篇文章里的“可能世界”，在统计推断中通常可以叫作 **hypotheses**。而我们对这些 hypotheses 的概率分配，可以叫作当前的 **belief**。

设隐藏状态为 `H`，观察到的现象为 `O`。贝叶斯更新写作：

```
P(H | O) ∝ P(O | H)P(H)
```

这个公式包含三个基本概念。

**Prior，先验概率：**在看到新 observation 之前，我们认为每个世界有多可能。

**Likelihood，似然：**如果某个世界是真的，我们有多大概率看到这项 observation。

**Posterior，后验概率：**看到这项 observation 之后，我们应该重新认为每个世界有多可能。

简单地说：

```
后验 ∝ 似然 × 先验
```

接下来，主持人走了过来。

## Chapter 2｜主持人为什么让换门更好

主持人知道奖品在哪里，并遵守三条规则：

1. 他不会打开你已经选择的 1 号门；
2. 他不会打开有奖品的门；
3. 他一定会打开一扇空门，然后问你是否换门。

如果奖品就在 1 号门后，他会在另外两扇空门中随机打开一扇。

现在，他打开了 3 号门。里面没有奖品。

你应该留下，还是换到 2 号门？

答案是换门。

原因可以用两句话说清楚：

> 你最初选中的概率只有 `1/3`，选错的概率是 `2/3`。如果一开始选错，知道答案的主持人就会被迫打开另一扇空门，把有奖品的门留给你换，因此换门恰好在那 `2/3` 的情况下获胜。

从 likelihood 看也一样。

设 `O` 表示“主持人打开 3 号门，而且里面为空”。

- 奖品在 1 号门时，他有一半概率打开 3 号门；
- 奖品在 2 号门时，他只能打开 3 号门；
- 奖品在 3 号门时，他不可能打开 3 号门。

所以这项 observation 在三个世界中的出现概率不同。更新之后：

```
P(H₁ | O) = 1/3    P(H₂ | O) = 2/3    P(H₃ | O) = 0
```

主持人并没有移动奖品。

他只是用自己的知识，选择性地排除了一个世界。

## Chapter 3｜同一扇空门，为什么会有不同含义

现在换一个主持人。

他不知道奖品在哪里，只是在你没有选择的 2 号门和 3 号门之间随机打开一扇。

他碰巧打开了 3 号门，而且里面没有奖品。

表面上，你看到的仍然是同一件事：

> 3 号门被打开，里面为空。

但这一次，1 号门和 2 号门的概率各是 `1/2`。

因为在奖品位于 1 号门和 2 号门时，这位主持人打开 3 号门的概率相同。这项 observation 排除了世界 3，却没有进一步偏向世界 1 或世界 2。

同一扇空门，在第一种机制下意味着 `1/3` 对 `2/3`，在第二种机制下意味着 `1/2` 对 `1/2`。

区别不在门，而在门是怎样被打开的。

因此，更完整的更新不是简单的：

```
P(H | O)
```

而是：

```
P(H | O, M)
```

其中 `M` 表示 **observation-generating mechanism**：这项观察是怎样被选择、产生和呈现给我们的。

证据不仅包括我们看见了什么，也包括为什么偏偏让我们看见了它。

## Chapter 4｜如果开门是你要求的呢

再改变一次规则。

这一次，没有主持人替你选择安全的门。你直接要求工作人员强制打开 3 号门，不管奖品是否在里面。

幸运的是，3 号门后仍然是空的。

1 号门和 2 号门的概率仍然各是 `1/2`。

这个数字与随机主持人的结果相同，但生成过程不同。

随机主持人打开哪扇门，是系统中的一个行为；它可能受到他的知识、规则或偏好影响。

而“强制打开 3 号门”是你从外部设定的动作。你不再只是观察一个变量取了什么值，而是在主动决定它取什么值。

因果推断通常用下面的区别描述两者：

```
P(Y | X = x)
```

表示观察到 `X = x` 后，怎样判断 `Y`；

```
P(Y | do(X = x))
```

则表示主动把 `X` 设置为 `x` 后，`Y` 会怎样变化。

在三门问题里，两种机制恰好可能得到相同的后验概率。但在更复杂的世界中，观察一项选择和强制做出一项选择，往往不是同一件事。

到这里，问题已经从“如何解释 observation”向前走了一步：

> 如果我们能够决定下一项 observation 怎样产生，应该选择什么？

## Chapter 5｜选择下一项 observation

把游戏扩大到一百扇门。

只有一扇门后有奖品。你先选择了 1 号门，选中的概率是 `1/100`，选错的概率是 `99/100`。

你可以请一位知道答案的主持人，在其余 99 扇门中打开 98 扇空门，只留下你的 1 号门和另一扇门关闭。

如果主持人按照这个规则行动，剩下那扇门就承接了你最初选错的 `99/100` 概率。换门的胜率是 `99/100`。

百门版本没有改变三门问题的原理，只是让一件事变得更明显：

> 主持人的价值，不在于他说了更多话，而在于他排除了大量原本可能成立的世界。

现在再加一个条件：每检查和打开一扇门，都需要付出时间或费用。

问题便不再只是“更多信息是否有用”，而变成：

- 应该检查多少扇门？
- 继续排除世界会不会改变最后的选择？
- 这种改变值不值得它的成本？

这时，行动就开始成为实验。

好的信息行动 `a`，应当让不同 hypotheses 对下一项 observation 给出不同预测：

```
P(O_next | H₁, a) ≠ P(O_next | H₂, a)
```

如果一个动作在所有可能世界中都会产生相同结果，它就没有区分力。

如果一个动作能让不同世界暴露出不同反应，它就是一个实验。

于是原来的线性过程：

```
观察 → 推理 → 结论
```

变成了一个循环：

```
观察 → 可能世界 → belief → 行动 → 新观察 → 更新
```

行动不再只是推理结束后的附属步骤。

它进入了推理本身。

## Chapter 6｜信息更多，不等于信息更有价值

一项 observation 能改变 belief，也不代表它值得获取。

一个智能体至少还要区分三件事：

1. **区分力：**它能多大程度地区分仍然存活的 hypotheses？
2. **决策价值：**这种区分是否会改善接下来的选择？
3. **获取成本：**为了得到它，需要付出多少时间、资源和风险？

有些信息排除了许多世界，却不会改变行动；有些信息能改变行动，但成本高于收益；还有些信息来自一个未知或带有自身目的的生成机制。

因此，主动智能并不只是“多问几个问题”。

它要决定：

> 接下来最值得知道什么，以及应该通过什么机制知道它？

这正是 active learning、Bayesian experimental design、active sensing 等领域共同关心的结构。

## Chapter 7｜那张地图里还缺少什么

上一篇文章已经把 possible worlds 对应到了 hidden state、observations、hypotheses、belief 和 action under uncertainty。

那张地图回答了一个静态问题：

> 在已经拥有一组 observations 的前提下，系统内部需要表示什么？

但它默认了一件事：observation 已经来到我们面前。

三门问题的几个变体补上了那张地图里缺少的部分。

| 三门问题中新出现的结构 | 对应概念 | 它补充的问题 |
|---|---|---|
| 主持人依据什么规则开门 | observation model / selection mechanism | 同一个 observation 为什么可能具有不同意义 |
| 决定请求主持人提供哪种信息 | active information acquisition | 智能体怎样选择下一项 evidence |
| 选择最能区分剩余世界的操作 | experimental design | 什么行动最能暴露 hypotheses 之间的差异 |
| 强制打开指定的门 | intervention / causal inference | 观察某事与主动造成某事为什么不同 |
| 开门需要付出费用 | value of information | 信息带来的决策改善是否值得它的成本 |
| 行动产生新观察，再更新 belief | agent–environment loop / POMDP | 推理为什么不是单向过程，而是循环 |

第二篇中的结构大致是：

```
O → H → B → A
```

已有 observations 限制 possible worlds，形成 belief，然后支持一次 action under uncertainty。

第三篇补上的结构则是：

```
Bₜ → Aₜ → Oₜ₊₁ → Bₜ₊₁
```

行动不只消耗已有 belief，也会改变下一项 observation 怎样产生，并由此改变下一时刻的 belief。

现实中的 AI 面对的当然不是三扇门，但它收到的信息同样不是凭空出现的。

搜索和检索系统决定返回哪些内容；用户决定提供哪些事实；工具接口决定暴露完整状态还是简单摘要；另一个 agent 也可能刻意选择信息，希望接收者形成某种 belief。

所以：

- 没搜到反例，不等于反例不存在；
- 工具返回“成功”，不等于真实目标已经实现；
- 一段文字出现在 prompt 中，不等于它拥有改变任务目标的权限。

在三门问题里，主持人的规则决定空门的意义。

在 AI 系统里，retrieval、ranking、tool policy、用户选择和其他 agent 的策略，也在决定 observation 的意义。

## Chapter 8｜推理之外，agent 还需要什么

在固定 context 上进行更长、更复杂的推理，能够更充分地利用已有信息。

但这不等于系统能够：

- 判断现有 evidence 是否已经不足；
- 理解 observation 的来源机制；
- 选择有区分力的新问题或行动；
- 区分被动观察与主动干预；
- 在环境机制改变后重新校准 belief。

长推理改善的是对现有信息的处理。

主动智能改变的是系统与信息之间的关系。

## Chapter 9｜这条线通向哪里

第一篇问：

> 一个系统应该保留什么信息和结构？

这是 representation 的问题。

第二篇问：

> 在真实状态不可见时，哪些世界仍然可能成立？

这是 hypotheses 与 belief 的问题。

这一篇继续问：

> 当已有 evidence 不足以区分这些世界时，系统怎样获得新的 evidence？

这是 active information acquisition 的问题。

三篇文章由此形成一条连续的路径：

```
Representation → Possible Worlds → Belief
→ Information Acquisition → Intervention → New Observation
```

第一篇讨论系统应该保留什么，第二篇讨论已有 evidence 允许哪些世界继续存在，第三篇则把这些组成部分连接成一个会持续运行的闭环。

这条路径接下来还会分出许多问题：

- 什么样的内部 representation 才能被称为 belief？
- 两项 observation 应该怎样比较价值？
- 当 observation model 本身未知时，系统怎样同时推断世界与信息来源？
- 当信息提供者有自己的目标时，普通的 Bayesian update 是否仍然可靠？
- 当行动改变环境和未来数据时，系统怎样避免形成 self-confirming beliefs？

它们分别通向 Bayesian decision theory、Blackwell information order、experimental design、causal inference、dual control、strategic information 和 learned belief representation。

但此刻最重要的转折已经发生了：

> 思考不是智能的终点。

当现有证据已经说完了它能说的一切，真正的智能开始决定——下一步应该让世界回答什么。
